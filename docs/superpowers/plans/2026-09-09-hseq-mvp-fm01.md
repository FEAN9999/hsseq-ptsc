## Global Constraints

Áp dụng cho **mọi** task; không nhắc lại trong từng task.

- **Ngôn ngữ:** toàn bộ chữ trên UI và mọi `detail` lỗi từ API là **tiếng Việt**. Không có nút đổi ngôn ngữ. `name_en` chỉ xuất hiện ở header nhóm (11px) và title khi hover.
- **Số qua API:** JSON **number** (float), không bao giờ chuỗi. pydantic 2.12 mặc định serialize `Decimal` thành chuỗi — dùng `JsonNumber` ở Task 9, không tự chế chỗ khác.
- **Thời gian:** mọi cột thời gian là `timestamptz`; mọi phép so và hiển thị theo `Asia/Ho_Chi_Minh`; không bao giờ dùng `datetime.now()` naive.
- **Kết nối DB (cloud):** `postgresql+psycopg://USER:PASS@aws-0-REGION.pooler.supabase.com:5432/postgres?sslmode=require` (Supavisor **session mode**, IPv4). SQLAlchemy `pool_size=5, max_overflow=5, pool_pre_ping=True`. Không dùng asyncpg.
- **Bí mật:** app **từ chối khởi động** khi thiếu `JWT_SECRET` hoặc `JWT_SECRET` là giá trị mặc định. `DATABASE_URL`, `JWT_SECRET`, `CORS_ORIGINS`, `APP_ENV` đọc từ env, không hardcode. Không commit `.env`.
- **Ngân sách query:** form `GET /reports/{id}` ≤ 2 query, `GET /dashboard/summary` ≤ 2 query, không N+1. Có test đếm query bằng event listener SQLAlchemy.
- **Không thêm thư viện UI.** Tailwind + native `<dialog>` + TanStack Query là đủ. Không component library, không icon pack, không animation library.
- **Chữ:** chỉ Inter (Google Fonts, subset `vietnamese`, weight 400/500/600, `font-feature-settings: "tnum"` cho mọi số). Không Roobert.
- **Cấm trong app** (thuộc phần landing của `DESIGN.md`): headline 52px, highlight span, mascot/minh hoạ, gradient, icon trang trí, card shadow, `max-width: 1200`.
- **Một chuyển động duy nhất** trong toàn app: ô KPI đổi số nháy nền `#c1e1f7` → trắng 600 ms (tắt khi `prefers-reduced-motion`). Ngoài ra chỉ hover nút 120 ms.
- **Màn hình đích:** 1280×800 ở zoom 100% **và** 125% (~1024px hữu dụng). Trang **không bao giờ** cuộn ngang; bảng cuộn trong khung riêng với cột đầu sticky.
- **Cache:** TanStack Query `staleTime` 30 giây + `refetchOnWindowFocus`; **mọi** mutation thành công gọi `invalidateReportQueries()`.
- **Git:** làm trên `master`; Render/Vercel trỏ nhánh `demo`; chỉ `git push origin master:demo` khi Playwright `demo-path` xanh. Đóng băng `demo` từ 28/09. Không dựng CI trước demo.
- **53 quyết định đã chốt** (27 eng review + 26 design review) — plan này **không mở lại** quyết định nào. Spec ghi `NO UNRESOLVED DECISIONS`.

```python
# backend/app/core/config.py
from pydantic_settings import BaseSettings, SettingsConfigDict

_MAC_DINH_CAM = {
    "",
    "change-me",
    "secret",
    "doi-chuoi-nay-bang-mot-chuoi-ngau-nhien-32-ky-tu",
}


class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", extra="ignore")

    DATABASE_URL: str
    JWT_SECRET: str
    CORS_ORIGINS: str = "http://localhost:5173"
    APP_ENV: str = "local"

    @property
    def cors_list(self) -> list[str]:
        return [o.strip() for o in self.CORS_ORIGINS.split(",") if o.strip()]


def load_settings() -> Settings:
    s = Settings()
    if s.JWT_SECRET.strip() in _MAC_DINH_CAM or len(s.JWT_SECRET.strip()) < 32:
        raise RuntimeError(
            "JWT_SECRET thiếu hoặc còn là giá trị mặc định. "
            "Đặt một chuỗi ngẫu nhiên ít nhất 32 ký tự rồi khởi động lại."
        )
    return s


settings = load_settings()
```

```python
                    AND k.start_date  >= COALESCE(c.ob_start, '-infinity'::date)
             ), 0) AS acc_prev

  CROSS JOIN LATERAL (
      SELECT COALESCE(array_agg(mp.period_key ORDER BY mp.start_date),
                      ARRAY[]::varchar[]) AS keys
        FROM reporting_period mp
       WHERE mp.template_id = c.template_id

                 SELECT MIN(k2.start_date) FROM counted k2
```

```python
# backend/app/domain/report_rules.py
"""Quy tắc FM01, thuần — không DB, không HTTP.

MA TRẬN agg_type × 3 CỘT (bản sao duy nhất còn lại ở frontend/src/features/report/cellPolicy.ts;
sửa một bên phải sửa bên kia)

  agg_type   | Lũy kế tháng trước | Tháng này        | Cộng dồn        | lưu vào
  -----------+--------------------+------------------+-----------------+---------------------
  sum        | tự điền, chỉ đọc   | NHẬP (bắt buộc)  | client cộng, ro | this_period
  counter    | tự điền, chỉ đọc   | nhập (tuỳ chọn)  | NHẬP (bắt buộc) | this_period + acc_total_entered
  snapshot   | trống              | trống            | NHẬP (bắt buộc) | acc_total_entered
  computed   | tự điền, chỉ đọc   | tự điền, chỉ đọc | tự điền, chỉ đọc| không lưu
"""
from dataclasses import dataclass
from decimal import Decimal

COT_BAT_BUOC = {
    "sum": "this_period",
    "counter": "acc_total_entered",
    "snapshot": "acc_total_entered",
    "computed": None,
}
COT_NHAP_DUOC = {
    "sum": {"this_period"},
    "counter": {"this_period", "acc_total_entered"},
    "snapshot": {"acc_total_entered"},
    "computed": set(),
}


@dataclass(frozen=True)
class IndicatorSpec:
    code: str
    agg_type: str
    decimals: int
    required: bool
    formula: str | None = None


@dataclass(frozen=True)
class CellValues:
    this_period: Decimal | None = None
    acc_prev_entered: Decimal | None = None
    acc_total_entered: Decimal | None = None


@dataclass(frozen=True)
class FieldError:
    indicator_code: str
    message: str


@dataclass(frozen=True)
class CounterCheck:
    status: str            # ok | lech | bo_qua
    expected: Decimal | None
    message: str


def required_for(agg_type: str) -> str | None:
    return COT_BAT_BUOC.get(agg_type)


def editable_columns(agg_type: str) -> set[str]:
    return COT_NHAP_DUOC.get(agg_type, set())


def _qua_thap_phan(v: Decimal, decimals: int) -> bool:
    return -v.as_tuple().exponent > decimals


def validate_values(
    catalog: list[IndicatorSpec], values: dict[str, CellValues]
) -> list[FieldError]:
    theo_ma = {i.code: i for i in catalog}
    loi: list[FieldError] = []

    for ma, o in values.items():
        spec = theo_ma.get(ma)
        if spec is None:
            loi.append(FieldError(ma, "Chỉ tiêu không có trong mẫu báo cáo"))
            continue
        nhap_duoc = editable_columns(spec.agg_type)
        for cot in ("this_period", "acc_prev_entered", "acc_total_entered"):
            v = getattr(o, cot)
            if v is None:
                continue
            if cot not in nhap_duoc:
                loi.append(FieldError(ma, "Dòng tự tính, không nhận giá trị gửi lên"))
                break
            if v < 0:
                loi.append(FieldError(ma, "Số không được âm"))
                break
            if _qua_thap_phan(v, spec.decimals):
                loi.append(FieldError(
                    ma, f"Chỉ nhận tối đa {spec.decimals} chữ số thập phân"))
                break

    for spec in catalog:
        cot = required_for(spec.agg_type)
        if not spec.required or cot is None:
            continue
        o = values.get(spec.code)
        if o is None or getattr(o, cot) is None:
            loi.append(FieldError(spec.code, "Ô bắt buộc, chưa có giá trị"))
    return loi


def evaluate_computed(formula: str, by_code: dict[str, Decimal | None]) -> Decimal:
    """MVP chỉ hỗ trợ phép cộng; thành phần trống coi là 0."""
    tong = Decimal("0")
    for ma in (m.strip() for m in formula.split(",") if m.strip()):
        tong += by_code.get(ma) or Decimal("0")
    return tong


def counter_check(
    prev_total: Decimal | None,
    this_period: Decimal | None,
    entered_total: Decimal | None,
) -> CounterCheck:
    if prev_total is None:
        return CounterCheck("bo_qua", None, "Kỳ trước chưa duyệt, không kiểm tra liên tục")
    if this_period is None or entered_total is None:
        return CounterCheck("bo_qua", None, "Chưa đủ số để kiểm tra liên tục")
    mong_doi = prev_total + this_period
    if mong_doi == entered_total:
        return CounterCheck("ok", mong_doi, "")
    return CounterCheck(
        "lech",
        mong_doi,
        f"Lệch công thức (kỳ trước {prev_total} + tháng này {this_period} = {mong_doi}). "
        f"Có reset (LTI / đầu năm)? Nên ghi lý do vào Ghi chú",
    )
```

```python
from datetime import datetime, timedelta, timezone

import jwt
from pwdlib import PasswordHash

from app.core.config import settings

_hash = PasswordHash.recommended()
THUAT_TOAN = "HS256"
HAN_GIO = 12


def bam_mat_khau(mk: str) -> str:
    return _hash.hash(mk)


def kiem_mat_khau(mk: str, bam: str) -> bool:
    return _hash.verify(mk, bam)


def tao_token(user_id: int) -> str:
    # payload chỉ sub + exp; không refresh token ở MVP
    payload = {
        "sub": str(user_id),
        "exp": datetime.now(timezone.utc) + timedelta(hours=HAN_GIO),
    }
    return jwt.encode(payload, settings.JWT_SECRET, algorithm=THUAT_TOAN)


def doc_token(token: str) -> int | None:
    try:
        payload = jwt.decode(token, settings.JWT_SECRET, algorithms=[THUAT_TOAN])
        return int(payload["sub"])
    except Exception:
        return None
```

```python
def require_permission(code: str):
    def _kiem(u: CurrentUser = Depends(current_user)) -> CurrentUser:
        if code not in u.permissions:
            raise ForbiddenError("Bạn không có quyền thực hiện thao tác này")
        return u
    return _kiem


def scope_org_unit_ids(u: CurrentUser, code: str) -> set[int] | None:
    """None = toàn TCT. Với quyền phạm vi đơn vị mà scope NULL → 403, KHÔNG mở toàn bộ."""

                "Tài khoản chưa được gán đơn vị. Liên hệ Ban ATCL để cấp lại quyền.")
        return {dv}
    raise ForbiddenError("Bạn không có quyền xem báo cáo")
```

```python
from sqlalchemy import event


@contextlib.contextmanager
def dem_query(engine):
    """Đếm SELECT thật sự gửi xuống Postgres — ngân sách form và dashboard là 2."""
    dem = {"n": 0}

    def _before(conn, cursor, statement, *a):
        if statement.lstrip().upper().startswith("SELECT"):
            dem["n"] += 1

    event.listen(engine, "before_cursor_execute", _before)
    try:
        yield dem
    finally:
        event.remove(engine, "before_cursor_execute", _before)
```

```python
def ghi_gia_tri(db, report_id: int, version: int, values: list[ValueIn], actor):
    # cùng khoá với apply_transition: FOR UPDATE rồi mới so version
    r = db.query(Report).filter_by(id=report_id).with_for_update().one_or_none()
    if r is None:

    if not r.state.is_editable:
        raise ForbiddenError("Báo cáo ở trạng thái không cho sửa")
    if r.version != version:
        raise ConflictError("Người khác vừa sửa báo cáo này",
                            state=r.state.code, version=r.version,
                            values=doc_gia_tri(db, r.id))
    loi = validate_values(catalog, {v.indicator_code: v.as_cells() for v in values})
    if loi:
        raise ValidationError("Dữ liệu không hợp lệ",
                              errors=[{"indicator_code": e.indicator_code,
                                       "message": e.message} for e in loi])
    for v in values:                       # CHỈ ô được gửi
        ind = catalog_by_code[v.indicator_code]
        q = Decimal(10) ** -ind.decimals
        row = upsert(db, ReportValue, report_id=r.id, indicator_id=ind.id)
        if ind.agg_type == "sum":
            row.this_period = _lam_tron(v.this_period, q)
            row.acc_prev_entered = None    # nhập sống: hai cột acc luôn NULL
            row.acc_total_entered = None
        ...
    r.version += 1
    r.source = "live"
    db.flush()
    return r.version, doc_gia_tri(db, r.id)
```

```python
# backend/app/services/workflow.py
"""Máy trạng thái FM01 nạp từ DB (workflow_state + workflow_transition).

     submit (report.submit)          approve (report.approve)
  draft ────────────────▶ submitted ────────────────────────▶ approved
  editable                read-only                            counts_in_totals
                            │   ▲                                   │
      return (report.return,│   │ submit                            │ reopen (report.return,
      requires_note)        ▼   │                                   │ requires_note)
                          returned ◀───────────────────────────────┘
                          editable; ghi chú admin hiện đầu form

Không dùng thư viện state machine: trạng thái là dữ liệu, thêm FM02 không sửa code.
"""
from datetime import datetime
from zoneinfo import ZoneInfo

VN = ZoneInfo("Asia/Ho_Chi_Minh")


def apply_transition(db, report_id, action, note, expected_state, version, actor):
    r = (db.query(Report).filter_by(id=report_id)
           .with_for_update().one_or_none())                       # (1) khoá dòng
    if r is None:
        raise NotFoundError("Không tìm thấy báo cáo")
    if r.state.code != expected_state or r.version != version:     # (2) compare
        raise ConflictError("Người khác vừa sửa báo cáo này",
                            state=r.state.code, version=r.version)
    tr = tim_transition(db, r.template_id, r.state_id, action)     # (3)
    if tr is None:
        raise ConflictError(f"Không thể {action} từ trạng thái hiện tại",
                            state=r.state.code, version=r.version)
    kiem_quyen_trong_pham_vi(actor, tr.required_permission, r.org_unit_id)  # (4) 403
    if tr.requires_note and not (note or "").strip():
        raise ValidationError("Thao tác này bắt buộc có ghi chú")

    truoc = snapshot(r)
    r.state_id = tr.to_state_id                                    # (5)
    r.version += 1
    r.source = "live"
    now = datetime.now(VN)
    if action == "submit":
        r.submitted_at = now
        if r.first_submitted_at is None:
            r.first_submitted_at = now
            r.is_late = bool(r.period.due_at and now > r.period.due_at)
    elif action in ("approve", "return", "reopen"):
        r.decided_at, r.decided_by, r.decision_note = now, actor.id, note

    db.add(AuditLog(entity="report", entity_id=r.id, action=action,   # (6) cùng transaction
                    actor_id=actor.id, before_json=truoc, after_json=snapshot(r)))
    db.flush()
    return r
```

Audit **không** `db.commit()` riêng: nếu ghi audit hỏng thì cả chuyển trạng thái rollback theo.

```python
# backend/scripts/reset_demo.py
"""Đưa DB về đúng trạng thái demo. KHÔNG chạy được trên production."""
import os
import sys

from sqlalchemy import text

from app.core.db import SessionLocal
from app.seed import seed_all

BANG_XOA = ["audit_log", "report_text", "report_value", "report", "opening_balance"]


def reset(db) -> None:
    for bang in BANG_XOA:
        db.execute(text(f"DELETE FROM {bang}"))
    db.flush()
    seed_all(db)


def main(argv: list[str]) -> None:
    if "--yes" not in argv:
        print("Cần --yes. Lệnh này xoá toàn bộ báo cáo và nạp lại từ fixture.")
        raise SystemExit(1)
    if os.environ.get("APP_ENV") == "production":
        print("APP_ENV=production: từ chối chạy.")
        raise SystemExit(1)
    with SessionLocal() as db:
        reset(db)
        db.commit()
    print("reset_demo xong")


if __name__ == "__main__":
    main(sys.argv[1:])
```
